auto_awesomeWhat is it?

lazy-html is a small add-on for Claude (Claude calls it a “skill”). Once it’s set up, just hand Claude whatever you want to organize — a piece of text, a list, a file, or even just a topic — and it builds you a pretty, clickable web page.

The result is a single file: save it and open it in any browser, send it to a friend, or put it online to share. You never write a single line of code.

rocket_launchHow to use it

Set it up once, then use it in any chat with Claude. Just four steps:

  1. Download lazy-html (the “Download” button above).
  2. Open Claude, go to Customize → Skills, click the + at the top right, and choose Create skill.
  3. Import the lazy-html file you just downloaded.
  4. Done! From now on, just tell Claude “use lazy-html to organize this” and answer a few quick questions (layout, style) — it does the rest.
